# Security policy

CNQ Spark is for scratch and non-production data only, is provided as-is, and has no support.

If you find a security problem in the files in this repository (the template, the portal form, the runbook or the scripts), report it privately to security@qumulo.com. Please do not report it in public.

Never post keys, passwords, subscription IDs or tenant IDs in public, including in a pull request.
